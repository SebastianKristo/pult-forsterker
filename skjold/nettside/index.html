Skjold S1
Streamingforsterker for skrivebordet
En streamingforsterker med AirPlay, Blåtann, internettradio og to AUX-innganger. Den har innebygd USB-bryter for PC-en, og alt styres med knapper.

Skjold Node
Nettverksspiller for rom uten forsterker
Node er en liten nettverksspiller med Raspberry Pi og 1,8″ skjerm. Den har de samme kildene og menyene som S1, og kan spille synkront med S1 via Lyrion.

Skjold Core
Skjold-programvaren på din egen Raspberry Pi
Core kjører på en Raspberry Pi 4 eller 3B/3B+ du allerede har. Skriv Skjold OS til SD-kortet med Skjold Flasher, koble til høyttalere eller en forsterker, og du får AirPlay 2, Spotify Connect, Blåtann og Lyrion-radio. Core har ingen kasse, knapper eller skjerm. Den styres fra appen, nettleseren, Home Assistant eller Homey.
