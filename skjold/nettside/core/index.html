Skjold Core

Skjold på en vanlig Raspberry Pi

Core er Skjold uten kasse, knapper eller skjerm. Flash et SD-kort med Skjold Flasher, koble Pi-en til høyttalere eller en forsterker, og styr alt fra appen, nettleseren, Home Assistant eller Homey. Den spiller i takt med S1, Node og Touch i andre rom.

SKJOLD CORE

Kom i gang med Core

Skjold på en vanlig Raspberry Pi 4 eller 3B/3B+, uten kasse, knapper eller skjerm.

1

Flash kortet

Åpne Skjold Flasher, velg Core og skriv inn Wi-Fi.

2

Koble til

Sett kortet i Pi-en og koble til høyttalere eller en forsterker.

3

Vent på første oppstart

Første oppstart tar 15–30 minutter mens Skjold installeres.

4

Åpne Skjold

Gå til http://<navn>.local:8765 eller bruk appen.

SPILLEKILDER

Kilder

AirPlay 2

Fra iPhone, iPad og Mac. Med AirPlay 2 kan flere rom spille samtidig.

Blåtann

Fra alle telefoner. Start paring fra appen eller nettleseren.

Spotify Connect

Velg Skjold i Spotify-appen. Musikken strømmes direkte, og telefonen kan legges bort.

Internettradio

Inntil 50 favoritter, med søk i norske kanaler og hele verden rett på skjermen.

INTEGRASJONER

Integrasjoner med Lyrion, Home Assistant, Homey og Spotify

LYRION MUSIC SERVER

Lyrion

Skjold vises som en spiller i Lyrion, med radio, favoritter, lokale filer og synkrone grupper på tvers av rom. Skjold kobler seg til en Lyrion-server du allerede har, eller kan kjøre serveren selv.

HOME ASSISTANT

Home Assistant

Skjold blir funnet automatisk som en mediespiller med kilde, volum og av/på. Den kan brukes i automasjoner, for eksempel radio når du kommer hjem.

HOMEY

Homey

Skjold vises som en egen enhet med eget ikon, og kan styres i Flows: start en favoritt, bytt kilde eller skru ned lyden.

SPOTIFY CONNECT

Spotify

Skjold er en Spotify Connect-høyttaler. Den krever Spotify Premium.
