INTEGRASJONER

Integrasjoner med Lyrion, Home Assistant, Homey og Spotify

LYRION MUSIC SERVER

Lyrion

Skjold vises som en spiller i Lyrion, med radio, favoritter, lokale filer og synkrone grupper på tvers av rom. Skjold kobler seg til en Lyrion-server du allerede har, eller kan kjøre serveren selv.

HOME ASSISTANT

Home Assistant

Skjold blir funnet automatisk som en mediespiller med kilde, volum og av/på. Den kan brukes i automasjoner, for eksempel radio når du kommer hjem.

HOMEY

Homey

Skjold vises som en egen enhet med eget ikon, og kan styres i Flows: start en favoritt, bytt kilde eller skru ned lyden.

SPOTIFY CONNECT

Spotify

Skjold er en Spotify Connect-høyttaler. Den krever Spotify Premium.

Skjold OS

Standby-skjermer

16 standby-skjermer: klokker, VU-metre, radioskala, vær og kalender fra Home Assistant. Velges på enheten, i appen eller på web.

Nattmodus

Dobbelttrykk på power-knappen starter nattmodus i huset via Home Assistant eller Homey.

Plugins

Sovetimer, vekkerklokke, morgennyheter, sangtekster, ListenBrainz/Last.fm, webhooks, volumtak, lyttehistorikk, barnerom-modus, radioopptak til NAS, MQTT-bro og Snapcast (beta).

Romkorreksjon

Mål rommet med mobilen og få en korrigert equalizer.

Apple Hjem

Skjold kan legges til i Hjem-appen via HomeKit.

Android og widgets

Mediekontroll og medieutgang på Android/Samsung, widgets og Live Activity på iPhone.

Proxmox

Skjold Core kan installeres som en container på Proxmox.

Equalizer per kilde

Egne profiler for AirPlay, Blåtann, radio, AUX og hodetelefoner.

Standby-klokker

Flere klokkestiler når enheten står i ro.

Grupper

Spill den samme musikken på flere Skjold-enheter samtidig via Lyrion.

Talebeskjed

Valgfri stemme ved bytte av kilde, på norsk eller engelsk.

Oppdateringer
