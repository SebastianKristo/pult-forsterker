Skjold Lab

A streaming amplifier, network players and a remote with open-source software. Drawn, printed and built in Norway.

Skjold S1
Streaming amplifier for the desk
A streaming amplifier with AirPlay, Bluetooth, internet radio and two AUX inputs. It has a built-in USB switch for your PC, and everything is controlled with buttons.
Learn more ›
Skjold Node
Network player for rooms without an amplifier
Node is a small network player with a Raspberry Pi and a 1.8″ display. It has the same sources and menus as S1, and can play in sync with S1 via Lyrion.
Learn more ›
Skjold Touch
Player with a 7″ touchscreen
Touch has a 7″ touchscreen, a Raspberry Pi and its own DAC with RCA and 3.5 mm. Control the music and rooms right on the screen.
Read more ›
Skjold Røst
Small speaker for bathroom, kitchen and kids’ room
Røst is a small active speaker with a 3″ driver, a display and radio favourites on top. It handles steam and plays in sync with the rest via Lyrion.
Learn more ›
Skjold Stav
Remote with a 2.8″ touchscreen
Stav controls Skjold, the TV, Apple TV and Home Assistant from one slim remote, with IR learning and activities like «Watch TV» and «Good night». It charges in Skjold Dokk. A build project, not tested yet.
Learn more ›
Skjold Core
Skjold on a plain Raspberry Pi
Core is Skjold with no case, buttons or display. Connect the Pi to speakers or an amplifier, and control everything from the app.
Read more ›
Skjold Core
The Skjold software on your own Raspberry Pi
Core runs on a Raspberry Pi 4 or 3B/3B+ you already own. Write Skjold OS to the SD card with Skjold Flasher, connect speakers or an amplifier, and you get AirPlay 2, Spotify Connect, Bluetooth and Lyrion radio. Core has no case, buttons or display. You control it from the app, the browser, Home Assistant or Homey.
