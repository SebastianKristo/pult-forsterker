OPEN SOURCE

Everything is open. Build it yourself.

1

Order the enclosure

Upload the sheet-metal and CNC files to PCBWay or JLC. The notes for the order are included.

2

Print the parts

The S1 front plate and all of Node are printed in PETG. With AMS, the logo becomes part of the print.

3

Flash the SD card

Skjold Flasher writes Skjold OS with Wi-Fi already set up.

4

Wire and start

Follow the manual. On first start-up, the display shows a QR code for setup.

View the code on GitHub
SKJOLD CORE

Get started with Core

Skjold on a plain Raspberry Pi 4 or 3B/3B+, with no case, buttons or display.

1

Flash the card

Open Skjold Flasher, choose Core and enter your Wi-Fi.

2

Connect

Put the card in the Pi and connect speakers or an amplifier.

3

Wait for the first boot

The first boot takes 15–30 minutes while Skjold installs.

4

Open Skjold

Go to http://<navn>.local:8765 or use the app.
