SELF-HOSTED

Self-hosted software

Software we build ourselves. Self-hosted, with no cloud services. Everything runs on your own hardware, whether that is Proxmox, Unraid, TrueNAS or Docker. The interfaces are in Norwegian.

DASHBOARD

Skjold Stack

A self-hosted dashboard for the homelab. It gathers every service, server and key figure on one page, and you set it up in the browser instead of in config files.

Skjold Stack is for anyone with a home server. Services like Plex, Home Assistant, Immich and Sonarr show up as tiles with live status, and widgets cover server stats, DNS blocking, Cloudflare tunnels, the media server, calendar and weather. Skjold Stack used to be called Labdeck.

Finds your services

Asks Proxmox (containers and VMs), Unraid and Docker/Portainer, and suggests new tiles automatically.

Edited in the browser

Drag and drop, several tabs and themes. No YAML files.

Live status and widgets

Ping and response time per service, CPU, RAM and disk, DNS stats, media server, Immich and Hytte Backup.

Keys stay on the server

API keys and passwords are stored on the server and never sent to the browser.

Runs anywhere

Docker, Unraid (Community Applications), TrueNAS and a Proxmox container with a single install script.

Technical

Node.js with no dependencies in the backend and a single HTML front end. Port 7575 in Docker.

BACKUP

Hytte Backup

Back up your home server to somewhere else, like the cabin, over Tailscale. Pick a folder, and Hytte takes care of the rest.

Hytte runs on a machine at the backup site, for example a Proxmox server at the cabin, and pulls data from the servers at home over Tailscale (WireGuard). No ports need to be opened to the internet. It is built for large folders, like the photo library in Immich.

Pick a folder in the browser

Browse the folders on the server at home and press «Choose», or paste a path.

Dedup and compression

Files are split into 4 MiB blocks, identical blocks are stored only once, even across jobs, and everything is compressed with zstd. After the first run, only what changed is transferred.

Versions and schedules

Runs every hour, every 6 hours, daily or weekly. You choose how long versions are kept, from 7 days to a year, and old versions are cleaned up automatically.

File browser in the archive

Browse every version, preview files, and download or restore a file or a whole folder to any machine. Checksums are verified with SHA-256.

Overview of the tailnet

Every device, latency, direct or via relay, runs in the last day, space saved and disk use, with a live log.

Alerts and widget

Alerts through Unraid on failure, and its own widget in Skjold Stack.

STATUS

Several backup sites replicating between each other, and encryption before transfer, are coming. Traffic is already encrypted by Tailscale (WireGuard).

Technical

Node.js 22 with built-in zstd. A single service on port 8090, systemd in a Debian LXC. Installed with one script from the Proxmox host.
