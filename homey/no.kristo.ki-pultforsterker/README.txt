Skjold er en familie selvbygde strømmere og forsterkere: Skjold S1 (2 × 50 W pultforsterker med skjerm, knapper og volumknott), Skjold Node (kompakt strømmer med OLED, knapper og knott) og Skjold Core (ren Raspberry Pi). Denne appen styrer dem fra Homey over lokalt nett (ingen sky).

Enheten viser og styrer: på/standby, kilde (Radio, AirPlay, Bluetooth, Spotify, AUX, USB – det enheten har), volum, mute, loudness, radiofavoritter (inntil 50) og hva som spiller nå. Skjold Node har i tillegg LED-lysstyrke og LED-modus, S1 og Node skjermlysstyrke.

Flytkort: når kilden byttes, når avspilling starter/stopper, hvis «spiller» / «kilde er», og handlinger for av/på, velg kilde, loudness, radiofavoritt, Bluetooth-paring, skjermlysstyrke, LED-ringer (Skjold Node) og omstart/avslåing.

Enheten oppdages automatisk (mDNS), eller legges til med IP-adresse. Kildekode, byggeveiledning og kretskort: github.com/SebastianKristo/pult-forsterker
